# 20elementos-htmcss

Este repositório foi criado para armazenar pequenas atividades e exercícios de HTML e CSS, com foco no estudo de elementos, layout e desenvolvimento front-end.

## Objetivo do projeto

O objetivo principal deste projeto é praticar e consolidar conceitos de:

- estrutura de páginas em HTML;
- estilos com CSS;
- responsividade;
- uso de componentes visuais;
- organização de arquivos em projetos front-end.

## Lição atual

A página atual representa a primeira atividade de estudos sobre frameworks CSS, com uma interface inicial e elementos visuais inspirados em Bootstrap e em conceitos de frameworks front-end.

### Conteúdo presente

- navbar com menu;
- seção hero/banner;
- cards informativos;
- blocos de vantagens;
- exemplo de layout responsivo;
- footer final.

## Estrutura do projeto

```bash
20elementos-htmcss/
├── index.html
├── styles.css
└── README.md
```

## Como visualizar

1. Abra o arquivo `index.html` em um navegador.
2. Ou utilize a extensão Live Server no VS Code para visualizar em tempo real.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap CDN
